Release Notes

VisualVM 2.2.2 has been released on September 8th, 2026. This document describes changes introduced by this release.

System Requirements

Supported OS:

  • Microsoft Windows
  • Linux: Intel platform, ARM HFLT, AArch64
  • macOS: Intel platform, Apple Silicon

Required Software:

  • Oracle JDK 8~26
  • OpenJDK 8~26
  • GraalVM 19 ~ GraalVM for JDK 26

Changes

Features and Enhancements:

  • GH-505: Monitor total allocated bytes on the Java heap by the JVM
  • GH-658: Add a check if "which" command exist
  • GH-659: [macOS] Honor the JAVA_HOME environment variable
  • GH-660: JDK26 Support

Fixed Bugs:

  • GH-657: Cannot initialize Polyglot Sampler in --module-path mode
  • GH-662: ClosedByInterruptException while computing Path to GC Root in Heap Viewer
  • GH-665: Heap dump comparison can fail with NullPointerException

Known Problems

To view all known problems please see the VisualVM Issues page.

To resolve the most common problems please follow the Troubleshooting Guide.
